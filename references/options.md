# Theme17 华为风格

本轻量版 Skill 仅提供一个主题：

| 主题 ID | 名称 | 适合场景 | 适用人群 |
| --- | --- | --- | --- |
| `theme17` | 华为风格 | 内部商业汇报、行业调研、白皮书、竞品分析、管理层汇报 | 企业管理层、战略与研究团队、咨询团队、B2B 团队 |

所有 `goal.json` 必须使用：

```json
{
  "themePack": "theme17"
}
```

直接指定页面时使用 `theme17_page001` 至 `theme17_page071`。前五页是封面候选；章节页为第 16、46、59、68 页。真实候选、角色、媒体槽和字段契约以 `layout:query` 与 `inspect:layout` 的输出为准。
