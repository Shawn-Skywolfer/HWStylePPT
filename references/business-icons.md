# 业务 ICON 版式

用户希望部分页面自动使用能辅助理解的图标时使用。无需联网或模型调用，不改变已确认文字和数据。不要求用户在脑图手填图标 ID。原版式保留；新变体有明确图标槽位和完整文字空间，不能在任意文本上覆盖图标。

| 布局 ID | 名称 | 内容块 / ICON 槽位 |
|---|---|---|
| theme17_content_icon_pillars | 能力支柱 | 2–3 |
| theme17_content_icon_list | 图标要点清单 | 2–4 |
| theme17_content_icon_risks | 分类风险分析 | 2–5 |
| theme17_content_icon_steps | 图标实施步骤 | 3–5 |
| theme17_content_icon_roadmap | 阶段演进路线图 | 2–4 |
| theme17_content_icon_media | 图文重点维度 | 2–4，另可显示 1 张图片 |

这些是上限范围，不是任意字量保证。自动匹配优先考虑内容角色、标题、视觉意图和真实关系；语义不适合、内容过长、结构化图表或非线性关系，不强行改成图标页。不能为填满槽位删减、截断正文或虚构关系。正文和来源均独立保留。图文混排关闭图片后展开文字区，不保留占位框；图片开启后兼容本地上传、链接导入和已授权 AI 生图。

## 自动匹配和提示

本地库精选 45 个统一风格 Tabler Outline SVG，覆盖团队、数据、算力、储能、光伏、航运、金融、政策、交付、制造、安全、流程等场景。以标题优先、正文辅助匹配；供应/资金/政策等具体概念优先于“风险”等通用词。无法明确匹配时使用中性支撑图标，并在右侧说明原因，不悄悄省略、显示乱码或填入黑方块。模型不能返回任意 SVG 或外链作为 ICON。

直接换版菜单显示本次候选实际可见数量；内容适配菜单显示支持数量范围，不能把最大容量当作本次实际数量。右侧显示“当前显示 N / M”。用户关闭某项或整页后数量随之更新。原有不含图标的版式不会被标为有图标。

## 编辑、锁定和恢复

点击正文图标或右侧“替换”打开本地搜索；支持中文类别和英文 ID。可修改深灰/华为红/黑色、24–56 的大小，默认深灰、不加红色背景。单项可隐藏、恢复自动匹配；整页可关闭或恢复自动。

颜色使用带文字名称的直接点选色块；大小使用 24 / 32 / 40 / 48 / 56 五个尺寸按钮，并显示当前 px 值。不再使用 ICON 颜色或大小下拉框。两组按钮均显示明确选中状态，支持方向键、Home / End 切换；重复点击已选值不新增撤销记录。后台任务轮询只更新任务状态，不得在 ICON 内容/配置未改变时重建设置区。保留右侧滚动位置和键盘焦点。

图标是视觉元数据，使用 `slide.visuals.icons` / 图标版式的 `props.iconConfig`，不属于正文。`overrides` 按稳定 blockId 保存，允许 id、visible、color、size；仅允许库内 ID、合法颜色与大小。布局转换通过内容快照迁移锁定，不靠原 DOM 索引猜测。AI 重新分组后，消失的 blockId 选择保留为未使用记录，不擅自套到新的内容块上；需要时用户重新选择。所有编辑支持撤销、重做和自动保存；恢复自动不发起模型调用。

`iconConfig` 的颜色等字段不受通用模板“清除私有颜色参数”机制裁剪。此例外只针对登记的 ICON 元数据，仍执行严格白名单校验，不放宽其他模板参数。

## 打包和导出

SVG 几何内嵌，标签仍为 HTML，遵守禁止 SVG 可见文字的校验。不使用字体图标、CDN 或运行时下载，附带 `project/assets/tabler-icons-LICENSE.txt`。库扩展需同时更新中文语义索引和许可，统一风格。

逐页核对完整文字、来源、关系、实际图标数量、图文重叠及图片加载；交互验收包含替换、开关、颜色/大小、撤销重做、刷新、图标→普通→图标换版保留，以及 PPTX/PDF 导出。SVG 优先保持外观，可能按导出器能力回退图片；不宣称每条 SVG 路径均原生可编辑。导出不包含搜索面板、按钮和取消图片的 X。
