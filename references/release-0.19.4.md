# 0.19.4 · 版式复用与文字宽度

## 版式复用：同一固定版式最多使用两次

- 固定版式（`theme17_pageNNN` 等非 `theme17_content_*` / `theme17_chart_*` 的已登记版式）在同一份演示中**最多使用两次**，替代此前的“全篇唯一”。
- 相邻正文页仍必须使用不同 layout ID；封面、章节、封底继续豁免。
- 新规则在整条链路上一致执行：规则选版、AI 视觉策划、单页换版菜单、AI 适配候选、历史恢复、整块删除后的重排、旧 goal 导入校验与 `validate:goal-spec`。
- 整套选版搜索改为“计数 + 预留”：显式指定同一固定版式两次仍然成立，第三次直接拒绝；非指定页只能占用剩余名额，不会抢占已预留位置。
- 未改动：封面唯一、章节最多四页、固定封底、内容/数据/来源/关系校验与浏览器实测。

## 文字宽度：解除模板里写死的副标题上限

- 演示控制台选中文字后新增“文字宽度”输入（120–1400px）与“恢复自适应”。
- 覆盖模板 CSS 中的 `max-width`（例如封面副标题的 `760px`），让文字在**所在分栏内**按实际可用宽度排版；不会越过分栏覆盖右侧面板。
- 行内元素自动转为 `inline-block` 以保证宽度生效；恢复时还原原内联值。
- 宽度与字号、颜色、字体使用同一套 `editorTextStyles` 持久化：自动保存、撤销/重做、刷新恢复，并在 HTML/PDF/PPTX 导出前应用。
- 界面文案已加入中英对照。

## 测试与验收

- 更新 3 处断言旧规则的测试（`layout-rhythm`、`layout-target-consistency`、`semantic-planning`）。
- `tests/content/*.test.mjs` 全量 315 项通过。
- 模板内联脚本语法校验：12 个脚本块，0 错误。
- `doctor` 安装自检通过。

## 已知边界

- 文字宽度只在分栏内生效；跨栏会覆盖相邻面板，属于构图变更，需单独确认。
- 已生成的旧演示内嵌旧版编辑器代码；需要重新生成或按受控方式同步运行时代码，才会出现“文字宽度”控件。
- 本次未改动封面、章节页、固定封底与任何已批准的视觉规范。
