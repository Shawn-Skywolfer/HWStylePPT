# HW 正文模板库

先遵循 [hw-visual-fidelity.md](hw-visual-fidelity.md)：所有模板及变体忠实原稿；任何必须偏离的视觉改动先给出同内容前后对照并取得批准。下文容量策略不是自动改变原稿构图或字号的授权。

## 范围与选择

`theme17_content_hw_table` 和 `theme17_content_hw_layers` 暂时隐藏新调用入口（注册表 `selectionHidden:true`）。生成、Agent 布局查询、原文换版和 AI 适配候选均排除这两类；对应原 Skill 模板优先，推荐键记录在 `preferredExistingLayouts`，仍须验证容量和内容语义。旧页面及其所有原稿变体保留渲染、编辑、导出和历史恢复，隐藏不等于删除资产。

结构化表格的确定性回退使用原 `theme17_page019`：3–5 行、2–4 列，第二列为短数值，四列时第三列为真实数值变化；表头、单元格及来源原样映射。行分组、重点单元格、额外列或超容内容不能静默丢失；没有无损原版式时提出选择/拆页确认，不绕回隐藏的 HW 表格。分层内容继续使用原主题检索和 `theme17_content_hierarchy`，不强制转成普通 Bento。

注册表为 `project/assets/hw-template-registry.json`，28 个显示名称和 layout 键逐项沿用上传包。原 Theme17 页面、生成元数据、固定封面/章节/封底及 Logo 资产不覆盖。HW 仅新增正文契约；封面仍为原前五个固定封面候选，章节仍为原 16/46/59/68 页，封底仍由原生成器自动追加。

精细、直出和单页换版都检索完整主题库。自动选择先使用可承载原文的原主题页面；HW 在完整内容无法映射到原模板时提供匹配的自适应候选。用户在版式菜单明确选择 HW 时，按其选择验证。不能仅为增加多样性把普通并列内容改为因果、层级或闭环。

Agent 可调用：

```text
node <skill-root>/project/scripts/layout-query.mjs --theme theme17 --keyword _hw_ --limit 40
node <skill-root>/project/scripts/layout-query.mjs --theme theme17 --role metrics --keyword _hw_ --limit 20
node <skill-root>/project/scripts/inspect-layout.mjs --compact theme17_content_hw_bento_dense theme17_chart_hw_line
```

正文必须继续使用具体 `layout + props`。HW 默认值只有空结构原型，不包含演示文案或可直接交付的示例业务数据；缺少真实指标、图表或完整内容时拒绝生成，而非补零。不要将结构字段 `blockId` 当作可改写文案。

## Family 与档位

| Family | 版式与容量 |
| --- | --- |
| 指标叙事 | 1+3 三行、1+3 三列两段、1+4 的 2×2、1+6 的 2×3 |
| Highlight | 并列、紧凑、中央强调，各 2/3/4 项；无 5/6/8 档 |
| Bento | 非对称 5/6/7；二加三标题带 5/6/8；高密度 4/5/6 |
| 图文 | 左图右文 3/4/5 条；上图下文 3/4/6 条；交错 2/3 组 |
| 图文 Bento | 大图主导 4/5/6 格；双图 5/6 格；多图矩阵 6/8 格。格数包含图片 |
| ICON | 卡片矩阵 4/6/8；左图标右正文 3/4/5；标题带 3/4/6 |
| 图表 | 原稿竖柱/饼图/折线/面积/雷达 3/4/5 格＝1 图＋2/3/4 个解读块；横条 3/4 格＝1 图＋2/3 个解读块，不留空槽、不补造分析。纯图使用其他兼容的已有图表版式 |
| 关系 | 双态转型、分层/金字塔/策略屋、中心辐射/双向/闭环均遵循原稿各注册变体的固定完整结构与块数，不自动扩充层数、节点或重画连接线 |
| 流程与表格 | 时间线 3/4/5/6/7/8 个节点，上下交错，原稿 4/6 档不变；流程数量 3/4/5/6 步独立于卡片/箭头链/价值链三种样式；原稿 6 步构图保持原样，少步骤只按原样式等宽排布；表格上限 4/6 完整行、2–6 列，真实 1–6 行均可用，不补行 |

所有档位仍须通过实际文字宽度、几何估算及浏览器实测。标题和正文的视觉字号以原稿对应变体为准；先前实现中的 18/17/16/15/14px 有限尝试只是旧容量算法，不代表这些字号已获视觉批准，不能据此自动缩字。超容时保留全文并提出换版、完整块拆页或必要的样式改动候选，按前后对照审批后应用，不隐藏、截断或改写确认稿。表格、图表、媒体、显式关系与自由排布不能静默拆分；表格拆页须由用户确认完整行的归属，不能拆散单元格或丢掉表头。

交错图文的行框沿用原稿472px内容区和20px行间距：2组每行226px，3组每行144px。空的逐块来源不生成灰条占位；非空来源仍完整显示。子框不得凭最小内容高度撑出行轨，正文放不下时明确拦截，不缩字或覆盖相邻行。混排圆环图必须等比缩放，不能继承混排区域的单轴压缩；浏览器校验检查实际圆形变换和图文子框边界。

生成前的 HW 候选先通过 `validateHwPlanningCapacity`，按原 family 的既有文字尺度估算正文、标题和来源高度；不能只数块数就判定“已匹配”。超容候选被排除后，容量规划可对无关系、无媒体/数据的独立内容做完整块拆页；单页要求、固定页数及60页上限继续生效。该估算不修改字体或原稿，也不代替生成后的浏览器实测；旧页面的手动编辑使用独立结构验证及浏览器检查，仍允许保留内容供用户调整。

紧凑指标页显式提供 `baselines` 时，在原有 mini-compare 区域渲染真实基线和当前值，以零线区分正负方向；不再只保存数据却继续显示演示柱。未提供基线时保持原稿输出不变，当前值待补充时不绘制虚构的零值柱。基线按 card.blockId 验证，不依赖可能为空的缓存 layout.nodes。

原稿每个变体有固定完整结构。“布局档位”是用户明确要求的槽位编辑：直接显示目标原稿变体，保留前面的内容块；缺少的槽位自动补齐，标题、正文、来源及目标所需字段显示“待补充”。目标槽位较少时，简短提示将移除末尾多少块/行，确认后从末尾移除，取消不改变页面。支持撤销/重做、自动保存和刷新恢复，不强迫打开编辑表单、不回脑图、不调用 AI。表格 4/6 档直接调整到对应行数，新增单元格用“待补充”；图表本身的数据不因解读槽变化而改动。新指标的数值为 null 并带 pendingValue:true，仅显示“待补充”，不得编造 0；用户填入真实数字后清除待补标记。此显式手动调整与 AI 无损适配、生成时的内容完整性校验分开处理；不得在用户未选档位时自动删稿。

版式卡片默认只保留选择器及必要操作。辅助信息移至有可访问名称的 info/tooltip；保留保存中、错误和删除后果反馈，不用常驻教程解释每一步。最终构图、颜色、连接线及档位样式继续忠实于原稿。

流程页“布局档位”显示 3／4／5／6 步，“呈现样式”使用卡片／箭头链／价值链三个按钮。修改样式不增删步骤；修改数量保留当前样式与前面的步骤，减少前简短确认、增加填入标题/正文/负责人周期/产出等真实可见槽位的“待补充”，不额外插入原稿没有的占位来源行。阶段数随数量更新，独立的责任角色等摘要不随意推算。步骤标题、正文、负责人/周期、产出分别绑定可编辑字段，不把编号或“产出：”前缀与字段合成一个编辑框；旧版文字和字体样式迁移到稳定字段 ID，支持多行、撤销/重做和保存刷新。

重点控件显示值 0＝不突出任何内容块，1/2/…＝对应块的红底白字标题。未手动调整时保留原稿原有重点，控件显示其首个重点编号，不再把有红色标题的状态标成 0。“原稿默认”与“无重点”用独立状态区分；旧稿默认状态迁移不抹掉原稿重点，手动选择 0 可保存、撤销/重做。折线/面积图曲线和面积几何沿用原稿，节点圆点用不受图表横纵非等比缩放影响的圆形标记，防止被拉成椭圆。

## 中性内容与数据

并列正文沿用 `blocks[{blockId,label,text,evidence}]`；图表和指标的数据独立存放。来源、标题、正文和数据不是一段自由 HTML。图片可在页面 `media` 或内容块 `media` 保存，均需是已经 stage 的 `assets/...` 路径；换版保留块级归属。

指标块：

```json
{"blockId":"delivery","label":"交付周期","text":"完整业务解释","evidence":"用户给定来源","data":{"kind":"metric","value":21,"unit":"天","delta":"对照基线的真实说明","detail":"独立详细说明","baseline":28}}
```

`baseline` 可省略；只在真实提供时绘制基线小柱。负值保留符号。指标叙事的第一块为核心指标，后续块为辅助指标，数量必须匹配档位。

图表块：

```json
{"blockId":"quarterly","type":"data","label":"业务量变化","text":"图表说明","evidence":"用户给定来源","data":{"kind":"line","labels":["Q1","Q2","Q3","Q4"],"values":[24,-12,48,36],"unit":"万元"}}
```

支持 column、bar、donut/share、line、area、radar，原 waterfall 不变。HW 横条按原稿实际高度收紧为 2–5 项、占比 2–6 项、竖柱/折线/面积 2–12 项；标签过长或过密会明确拒绝。雷达固定四维；HW 柱/条/折线/面积默认采用从 0 起算的自动范围，也可选择固定 0–100；真实数值不变。雷达四维真实值仍为 0–100，显示范围可自动或固定。合法负值可使用已有原生柱/条/瀑布图。饼图非负且合计 100%。空值、数值字符串、超出有限计算范围不补零、不取绝对值。当前 HW 图表为单数据系列，不丢弃多系列强行匹配。初稿前读 [chart-data-editing.md](chart-data-editing.md)，统一项数与标签安全边界；控制台可增删数据项，不改变独立解读槽。

渲染 props 中图表为 `chart:{type,unit,items:[{label,value}],series:[]}`。数据编辑器读取原结构，SVG 只负责几何，标签/图例/单位/来源用 HTML。表格为数据块 `data:{kind:"table",headers:[...],rows:[{cells:[...],group:"...",emphasis:"1,3"}]}`；`emphasis` 是从 0 开始的重点列索引，可传数组，由适配器规范化。表头与每行长度须一致。

## 控制台复用

整块选中框只在边框和缩放手柄接收拖动事件，内部区域透传给文字；点击块内文字切换到文字选择，双击进入编辑。点击页面四周空白取消选择，按实际页面边界判断，不因溢出的子元素仍属于页面而锁住选择。拖动/缩放结束释放指针捕获，保留撤销/重做。

- 图表沿用“图表数据”二级菜单。合法修改立即重绘，保存、撤销重做和刷新恢复沿用原链路。饼图允许先编辑多项，再点“应用图表数据”；总和错误保留数据草稿并提示，原页面不变。取消数据草稿不会改正式图表。
- ICON 使用现有 45 个本地业务图标，不引入第二套库。自动匹配、手动替换、尺寸/颜色/显隐按稳定块 ID 保存；菜单显示实际 ICON 数量。图标不属于“装饰文案”。
- 图文版式使用现有图片设置与来源菜单。各框独立支持开关、本地上传、链接导入、AI 生图、按框比例裁切、二次替换和取消；AI 默认关闭，真实生成前确认 Prompt 和计费。关闭全部图片时重排成全宽正文，不显示替代红图。
- 单页换版使用现有任务队列、内容映射、并发限制和串行应用；候选不能覆盖后续编辑。页码是自动内容，不参与可编辑文本的差异归属。

### HW 原稿版式与 HW·设计感版式之间换版

“当前页排版样式”分组标明“HW·设计感版式”和“HW 原稿版式”，各自区分原文直接换版与需 AI 适配。HW·设计感版式指 Skill 原有的 Theme17 正文/图表/ICON 版式，不表示切换整套主题或更改固定封面、章节和封底；内部 existing/hw 分组标识不变。

可识别的原生 HW 页面即使由传统 `goal + props` 生成、没有脑图映射，也可从当前结构化参数安全提取内容，不要求用户回脑图重新生成。原稿的 heading/date/meta/output/items 和独立正文均完整保留；原稿专用的补充文字保留为补充内容，不冒充来源。图表数据、表格、指标保持结构化，不为增加选项把数据压成普通文字。图片保留本地引用，上传的栅格 data URL 可安全落盘；ICON 的稳定块 ID 与配置保留，只提供具有 ICON 槽的目标。未知旧 HTML 仍不能靠抓取文本猜测内容映射。

只展示契约匹配的候选；正式应用前仍须通过真实浏览器检查。字段容量匹配不保证实际排版可容纳，超容保留原页并给出原因，不截断、缩字或重新设计原稿。指标/表格、关系图、折线/面积/雷达等如果没有可承载相同结构的 HW·设计感目标，可以没有直接换版选项，不能以虚构数据或改变关系来强开模板。AI 适配仍要求可验证的原项目与原宿主绑定，未绑定的验收预览不借用其他 Agent。

换版、撤销、重做与自动保存共用有序保存路径。Windows 目标文件被短暂占用时仅有限重试原子替换，不删除原文件、不以不完整覆盖代替安全保存；最终失败明确提示未保存。

## 验收与边界

运行 `npm run test:content`、`npm run test:content:hw`，并执行 icons/images/capacity/direct 回归。HW 回归覆盖每个档位的浏览器测量、真实组件生成、单页换版、数据重绘、图片上传裁切、撤销重做、保存恢复及 PPTX/PDF 导出。测试素材/数值只存在于测试文件，不作为生产默认值。

HW 保持可编辑 HTML 和现有导出机制，不承诺 PPTX 中每幅 SVG 都转换为 Office 原生图表或表格数据对象；二次编辑数据的入口是 HTML 演示控制台。PPTX 中文字仍可编辑，复杂几何可能保留矢量图。安装字体和 Office 渲染差异仍需目标电脑验收。本轮不修改其他电脑的已安装 Skill、宿主配置或用户旧演示；旧 HTML 需受控同步运行时代码或用新版生成，不能认为替换安装包会自动改写旧预览。
