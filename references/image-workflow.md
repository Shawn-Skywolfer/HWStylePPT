# 可选配图工作流

适用：用户希望部分正文页使用本地图片、图片链接或已配置的文生图模型。AI 默认关闭，不因切换版式、打开对话框或读取页面内容而调用模型。

## 用户入口

控制台按“图片设置 → 配图与 AI 生图 → ICON 设置”组织，先控制图片框显示，再选择来源。上述面板及弹窗复用控制台的卡片、按钮、字体和亮暗主题，不改变幻灯片本身的品牌色或已保存内容。

1. 在 PPT 演示控制台的“当前页排版样式”选择标有“可配图 · 最多 N 张”的合适版式。菜单仍只列能完整呈现当前内容的候选，不能为了图片截断文字；需要内容适配时仍先审阅候选。
2. 在“图片设置”逐个打开所需图片框。全部关闭沿用无媒体排版，不保留红色占位元素。封面、章节和固定封底不开放此功能。
3. 点击图片框，或“配图与 AI 生图 → 图片 N · 选择来源”。支持：
   - 本地上传：选择 PNG、JPEG、WebP，进入可拖动/缩放的裁切窗口。
   - 网上链接：输入公网原图链接，点击“下载图片并预览”。当前窗口仍打开且图片框未变化时，成功后自动进入裁切；后台完成的候选可点“预览并裁切”。网页地址、登录链接、内网地址和 SVG 不支持。此操作独立于 AI 开关，不读取/保存模型凭据，也不调用模型。
   - 浏览器通道：服务端因 Fake-IP 等原因无法下载时，可明确点击“浏览器通道下载并裁切”。先检查 URL 和 DNS，拒绝真实内网、混合私网解析和本机地址；仅公网域名的纯 198.18/19 合成解析可进入此浏览器路径。浏览器使用自身已有网络，不带登录凭据、Referer，不跟随跳转、不修改代理或 DNS。仍受网站 CORS 限制；失败时提示“浏览器打开原图 → 保存 → 本地上传”，不能通过此功能绕过访问控制。
   - AI 生图：开启开关，确认图片服务，输入 Prompt 或“读取本页内容到 Prompt”；审阅并去除敏感内容后点击“生成一张”。不再额外勾选同意，按钮点击本身是本次调用的明确操作；开启开关、打开窗口或读取本页内容都不调用模型。每次只生成一张，不自动重试。
4. 确认裁切后替换对应图片，其他图片框不变。可再次点击替换、取消图片、撤销/重做；确认图使用现有自动保存和导出链路，刷新可恢复。

## 模型与凭据

生图直接使用图片生成接口，不调用内容修改用的聊天桥接。支持 `/images/generations` JSON 协议、`data[0].b64_json` 或公网 `data[0].url` 返回。当前真实验收模型为 aihubmix `gpt-image-2.5-flare`，Base URL 为 `https://aihubmix.com/v1`。其他模型的参数可能不同，不声称任意图片模型均兼容。

项目绑定 DeepSeek Harness 时，读取所绑定 home 下 `profiles/desktop/cordis.patch.yml` 的图片模型路由。只解析固定格式的 providers/baseURL/models/apiKeyEnv，不执行 YAML 表达式。凭据按该路由的 apiKeyEnv 精确读取：进程环境、宿主 `.env` / `profiles/desktop/.env`，或 `.credentials.yaml` 中同名标量。未找到、为动态/加密存储、格式不支持时明确提示独立配置，不寻找其他账户或借用聊天密钥。

独立配置只接受 HTTPS Base URL。用户输入的 Key 仅存于本机项目 `.private/image-provider.json`，不进入 HTML、PPTX、Skill 安装包或诊断。复用宿主时只保存选择，不复制宿主 Key。图片功能的服务接口只允许本机同源请求。

## 比例、候选与恢复

按当前图片框实测比例计算宽高。当前 GPT Image 路线使用约 100 万像素、16 的倍数、比例 1:3 至 3:1 的合法尺寸；超出比例先选最近支持尺寸，最终裁切窗口精确匹配图片框，不拉伸。不得将图片模型生成的文字或数值当作真实图表数据；图表继续使用可编辑几何和 HTML 标签。

服务端图片任务最多并发 2 个，最多 10 个待处理任务；显示排队/模型等待/下载/候选就绪、实际耗时和错误代码，不编造百分比。URL 下载总等待上限 60 秒，AI 生图上限 10 分钟。可取消本地等待；提供商可能已接收请求并计费。只有裁切确认才修改页面。候选是临时结果，服务端候选 30 分钟后或服务重启后可能丢失；浏览器通道候选保留在当前网页内存，刷新即消失。需要保留时及时确认裁切，已确认图片不受此影响。失败保留原图，不自动重试；失败后可手动重新导入。同框进行中任务返回真实任务状态并禁止重复提交；同链接已就绪候选复用，不重复下载。当前图片框链接草稿只保留在网页内存，不进入日志或安装包。日志只含阶段、耗时、错误代码等，不包含图片 URL、Prompt、模型正文或凭据。

侧栏历史仅显示当前稳定 slideId 对应的图片任务，不混入其他页；来源弹窗再按 slideId 和图片框编号筛选。翻页不取消其他页的后台任务，切回原页仍可查看并裁切原候选。已关闭图片框的候选仍属于原页，不会转移到同编号的其他页。

## 企业代理与告知页

新服务只继承启动环境中已经配置的 HTTP(S)/ALL_PROXY、NO_PROXY；已有代理且没有明确关闭 NODE_USE_ENV_PROXY 时为子服务设置 NODE_USE_ENV_PROXY=1，不修改用户级或系统级变量。运行时是否支持环境代理仍需实际验证，不声称所有 Node 版本都一致。没有配置时不猜测公司地址，不改变网络出口。

模型请求不跟随重定向，不向重定向目标转发密钥。302/其他跳转提示 IMAGE_NETWORK_CONFIRMATION_REQUIRED，HTTP 407 提示 IMAGE_PROXY_AUTH_REQUIRED，200 HTML 告知/登录网页提示 IMAGE_NETWORK_PORTAL；连接失败不直接断言公司封禁全部 AI 域名，也不保证“没有计费”。让用户通过系统浏览器按企业批准流程处理，必要时联系 IT；不得生成自动签名、自动确认告知页或规避访问控制的脚本，也不收集电脑/域密码。

图片下载只允许公网 HTTP(S)，校验每次跳转和 DNS，并固定解析地址防止重绑定；最多 3 次跳转，15 MB，PNG/JPEG/WebP 魔数校验。浏览器解码限制 4000 万像素。不能把限制作为绕过内网访问控制的工具；内网图片请自行下载后本地上传。

若本机代理使用 Fake-IP（例如将公网域名解析为 198.18.x.x），服务端明确返回 IMAGE_URL_FAKE_IP，不下载也不放宽内网保护。此时可手动选择浏览器通道，或浏览器保存后本地上传。失败提示不会再被“已加入队列”覆盖。2026-11-02 实测用户提供的 cdn.pixabay.com 链接：服务端解析到 198.18.2.113 被拦截；浏览器 CORS 通道返回 HTTP 200、JPEG、172398 字节。这不代表其他网站均允许跨域读取；CORS、网络、跳转失败须明确反馈，不宣称所有外链均可用。

官方参数参考：[GPT Image](https://docs.aihubmix.com/cn/api/GPT-Image-1)、[模型 Schema 发现](https://docs.aihubmix.com/cn/api/async-tasks)。按实际模型的 `/call/schema/models/{model}/endpoints` 中对应路径核对参数，不能把聊天模型的 API 标识直接当作图片协议。
