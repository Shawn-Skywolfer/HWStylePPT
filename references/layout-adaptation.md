# 原主题版式的内容适配

普通换版不改内容；“需 AI 适配”明确允许提出精炼、分组和层级调整，但不自动应用。菜单探测原模板的字段、内容组数量、来源、媒体与容量，当前按实际字段用途提供风险、结论、明细/分层/多维表格、步骤/时间线、重点卡、三角支撑关系、阶段演进、图标要点等原 Theme17 版式；不为凑数量把数字指标页列成正文候选。已经可直接匹配的版式不重复列在适配组；当前套装已使用的不可重复固定版式被排除。

不是宣称 71 个模板随便套。需要额外事实、真实数值、特殊数据结构、不能隐藏的辅助区或未登记映射的页不会仅因好看被强行启用。结构探测用合成短句判断容量，合成短句绝不会成为最终内容。实际 AI 候选必须重新通过目标契约和浏览器验证。

适配前另按当前页完整来源计算独立来源区的最低容量，结构探测缓存不能绕过逐页来源筛选。连原始来源的去重最短串都放不下的目标不出现在 AI 适配菜单，避免为必然失败的任务耗时调用；优先使用可保留完整来源的原文换版。不能为了短来源区删掉“未核验/假设”等限定。单页候选使用该页论点进行文案相关性校验，不要求它包含整册标题关键词；整册生成的相关性校验不变。公开数量字段与内部名按同一别名契约读取，两者同时存在而数值冲突则拒绝。

## 交互

### 关系预检与确认

探测目标时优先保留当前关系与模式，不能把不同模式探测出的容量混为一个目标契约。流程、因果、层级或自由连线转为并列图文时，菜单标记“需关系确认”；未勾选独立授权前，后端以 `LAYOUT_RELATION_APPROVAL_REQUIRED` 拒绝入队，不调用模型。来源最低容量、角色、媒体和真实几何容量仍需同时满足。

允许关系适配只允许提出候选，不授权丢弃连线所代表的含义。目标不支持连线时，原关系必须逐条落实为目标正文中的可见句子，`relationMap` 记录原端点、关系类型、目标块及逐字可核对的句子，并保留原端点标题与关系标签。来源和数值仍按原规则保护。未经授权增加、反转或修改关系也会被拦截。候选窗口显示关系去向供用户核对；程序检查结构与可见文本，不能冒充已证明语义等价。未完成关系映射为 `ADAPTATION_RELATION_UNRESOLVED`，修订反馈针对具体关系，不当成字数超容反复重试。

图文 ICON 目标按真实图片框存在时计算几何容量，不能用无图片的宽正文预算误导适配。保留原内容的兼容流程/关系版式优先作为快捷路径；用户仍可直接在当前画布插入、增删和编辑，不需要返回脑图。

### 原始版式与页面历史

“原始版式 / 历史版本”是独立入口，也在版式下拉框的独立分组中出现，不受当前内容推荐列表过滤。首次换版前记录原始版式快照，已应用版本与原始快照保存在本机 `.layout-history` / `.layout-cache` 中；旧预览只从同页已应用任务的可验证前置快照恢复，不根据相似页面猜测。刷新、重启及后续换版不丢失原始入口；缺少旧快照时明确说明，不虚构可恢复版本。

恢复有两种明确方式：① 只换回所选版式，保留当前内容，仅在完整内容能通过目标原稿档位的匹配与容量检查时允许；② 恢复所选快照的版式和当时内容，必须说明会替换当前编辑。两种方式均先确认恢复方式，再进行本地渲染、页面实测和候选确认，不调用模型，不自动修改其他页，应用后可撤销/重做。原样恢复快照时不把当前页的后加文字样式覆盖到原稿上。不得为了恢复入口绕过固定版式唯一性或页面归属检查。

### 真正删除整个内容块

不再提供“内容块管理”面板。画布内单击选中文本框，双击或 Enter 编辑；Esc 结束编辑，点击空白提交文字并取消选中。非文字输入状态按 Del 删除选中的文本框；编辑状态中的 Del 仍只删除字符，不误删整块。点击内容块边框或空白处选中整块，再按 Del 删除；可撤销/重做，不自动改脑图。

HW 原稿先寻找同版式中数量恰好等于剩余内容块数的原始档位，通过真实渲染检查后直接重排，不弹出审批表单，不用空槽凑数。不丢弃剩余文字、样式、图表、图片与 ICON；重点跟随原块身份，删除重点块则取消重点。没有同版式档位时保留当前构图进行自由编辑，不自动改用别的原稿，也不强迫进入换版或脑图流程。

同版式删除直接在当前页完成并保存可恢复快照。自由编辑模式中，没有恰好匹配的原稿档位时直接在当前构图中记录移除，用户可继续拖动和调整剩余元素，不再强迫选择其他模板或返回脑图。删除最后一块也不会擅自删除整页。原稿库不修改；当前页删除记录与撤销快照单独保存。后续主动换版时，以当前可见内容而非旧脑图为基准。

### 当前页独立编辑

ICON 是可恢复的视觉状态，不是“以后只能使用 ICON 版式”的限制。普通、图文、图表或 ICON 目标只按内容、数据、关系、容量、邻页与固定版式复用规则筛选；图标手动选择保留在中性视觉快照中，暂不显示不等于删除。不能因页面存在 `visuals.icons` 就过滤掉所有无 ICON 槽的目标。

控制台顶部“插入”包含文字、内容模块、矩形、连线、箭头、图片、ICON、图表、表格；“查找”仅检索当前页。新增组件以稳定 ID、位置、尺寸、文字、样式及真实数据保存在 `state.props[slideId].editorCanvasObjects`，原组件移除记录保存在 `editorRemovedBlocks`。当前草稿与脑图隔离，不要求脑图确认或回写。文字双击/Enter 编辑、Esc 退出；Del、复制、拖动/横纵向缩放/Shift 等比例、数据编辑、保存刷新均支持撤销/重做。

新增图表为 2–12 项，空值 `null` 只显示待补充，不补零；新增表格为 1–20 行、1–8 列。原模板图表仍沿用各自已经登记的边界。ICON 使用同一本地图标库；新增图片使用 100–199 的稳定框编号，复用原图片来源与裁切流程。只有已保存的真实图片组件才能请求本机图片服务，不以编号绕过页面归属校验；AI 默认关闭，不因插入图片自动调用模型。

换版与 AI 适配读取当前编辑后的内容：排除已删除块，纳入新增文字、模块、图表、表格和配图。仍待补充的数据或空图片框在当前页处理，不虚构事实。纯图形和 ICON 不冒充事实内容；换版时保留这些手动图形，显式恢复整页历史快照则以该快照为准。任何自动换版失败不阻止当前页继续编辑、保存或导出。

调试接口：POST `/api/layout-history` 返回同页原始与历史版本及是否可保留当前内容；POST `/api/layout-restore` 提交明确确认的恢复方式；POST `/api/layout-delete-block-options` 计算整块删除后的匹配档位；POST `/api/layout-delete-block` 提交已确认的删除与重排。上述端点复用同源、队列、页面快照及候选应用保护，不借用其他 Agent，不调用模型。

### 直接调整内容槽（不调用 AI）

HW 正文“布局档位”直接显示目标原稿构图。多出的槽填“待补充”，指标数值留空、不能补零；减少时简短提示将移除末尾多少块或行，确认后执行。原稿样式不变，可在页面直接编辑，支持撤销/重做、保存和刷新；不再强制打开多栏表单或回脑图。AI 适配仍是独立入口，必须明确执行并先审阅候选。

### 字段用途与真实页面修订

字段名称不能代替真实用途。inspect 的 copyRoles、fieldContracts、fillPlan.itemFields 统一标注字段语义。Cases 的 `cases[].lead` 是大号数字指标（numeric-display），不是正文；普通段落不进入此字段、不作为 AI 正文适配候选。直接提供模板参数也检查该字段是否为真实数字展示串；合法原稿数字案例模板和视觉样式保留。不能把短段落当数字、造数或缩字号来强行启用。旧任务重试读取当前候选清单，不适合时直接解释原因，不再次调用模型。

每次适配至多两轮调用，共用一个预算：结构/事实/来源检查与真实渲染/浏览器检查都在轮次内。第一轮若内容或浏览器检查失败，将具体 blockId、字段、目标路径和可见区域信息反馈给原执行器，再返回完整候选。第二轮重新核对原始稿，而不是以失败候选作为原稿；仍失败就停止，原页与确认稿不变。没有“内容两轮＋浏览器再两轮”的额外调用。取消、超时、启动失败和网络故障不因此自动重发。阶段与修订次数进入脱敏 LOG，不写提示词或候选正文。

AI 配置窗口首先显示耗时与失败风险：可能需要数分钟，最多 2 轮调用，动态解释所设单轮等待上限及排队/渲染/校验额外耗时，不给出未经测量的成功率或确定完成时间。确认按钮写明“了解风险，加入队列生成候选”。候选确认前保留原页，失败/取消不替换；已发生调用可能产生用量。暂停会终止本轮，继续可能重新调用，不是断点续传。可返回查看“原文直接换版”，不发送生成请求；该方式不调用 AI、不改写正文，但仍通过页面校验。

表格版式可能要求正文整理为表格结构。配置框必须显式勾选授权，未勾选不调用模型；`allowRoleChange:true` 只授权目标正文→表格角色元数据，不授权编造表格数据或改变其他页面。模型提示使用目标角色，程序仅在已授权范围内同步此元数据。处理后再次展示结构转换及完整候选，用户确认才应用。非表格候选不得擅自变成封面等其他角色。刷新保留 `layoutOverrides`，旧版已丢索引时仅用当前保存模型精确匹配且中性内容唯一的已验证快照恢复；不满足则明确停止，不使用旧稿替代。

1. PPT 右侧选择“更多原主题版式 · 需 AI 适配并确认”，查看目标允许的组数，可授权重新分组并补充要求。
2. 默认沿用原项目绑定的 Agent；可显式选择该项目已经配置的模型服务。独立预览记录其生成宿主；旧独立预览可通过右侧“Agent 连接设置”显式连接原生成环境，无需重新生成内容。不会因为 PATH 中存在其他 Agent 就自动切换，也不复制凭据。未连接或入口不可用时，前端禁用开始按钮，后端在入队前拒绝请求；不会制造必然失败的队列任务。
3. 显示 AI 处理、事实校验、目标版式渲染、浏览器实测等进度；支持暂停/继续/取消。继续重新执行安全步骤，旧 runId 不得覆盖新结果。每次最多两次内容适配尝试，第二次只根据具体校验反馈修订。
4. 完成后显示完整处理前/后内容、精炼与分组说明、原块去向、关系变化、受保护项检查及真实 16:9 版式预览。关闭窗口只是稍后审阅；右侧可重新打开。拒绝或取消不改页面。
5. 用户明确确认内容、分组、关系和相关文字样式调整后才应用。本页等待期间有新编辑则拦截；改写字段采用新版式样式，未改写且可唯一匹配的文字尽量保留样式。支持撤销/重做与自动保存。

## 保护和审计

## 跨页任务工作区（0.10.0）

从 0.10.3 起支持单项删除与“删除所选”。允许已完成、暂停、失败/冲突停止或取消状态，且该任务不再占用后台执行名额；刚暂停/取消仍在结束进程时不能删除。排队、运行、待确认、待应用与已拒绝记录不允许删除。删除确认说明会移除任务及其 LOG，不影响页面/原稿/撤销栈；需要留证先导出。批量选择混合状态时，确认窗口明确列出可删项及保留数量；接口对所提交 ID 全量预检，任何一个不合格整批拒绝。POST `/api/layout-delete` 接收 `{ids:[...]}`。清理后刷新不再显示记录，不清理可能仍被页面/撤销引用的已验证版式缓存。

- 右侧只锁定当前页的活动任务。其他正文页可继续选择版式、提交独立任务；同一页只能有一个排队/执行/暂停/待确认任务。默认并发 2，可在底部设置 1–4；调小并发不会强杀已经运行的任务。
- 底部窗格统一显示页面、目标版式、阶段、进度、耗时、最近宿主信号和错误。勾选多个任务后可批量暂停、继续、取消。排队任务可用箭头或拖动排序，已运行任务不抢占；不可重复的原模板由活动任务预留，防止两页生成冲突版式。
- 暂停/取消会停止本次原宿主进程树，清理结束后才释放名额。继续从安全阶段重新执行，并非在模型内部断点续传。旧 runId 的迟到结果不能覆盖新执行。待确认候选不占并发名额，可以稍后逐个审阅。
- 底部“新任务等待上限”和提交候选窗口可明确调整单次 AI 调用至 1–600 秒，默认沿用原项目配置（通常 180 秒）。排队、渲染、校验耗时另计；内容或真实页面校验不通过最多反馈修订一次，因此整项任务可能包含两次模型调用。并发过高仍可能触发服务限流，建议从 2 开始。
- 每次调用使用独立目录和 DeepSeek 补丁，绝不共享会互相覆盖的调用配置。DeepSeek 有效 final 事件到达后回收本次进程，不为等待 CLI 自身退出而误报超时。阶段进度不伪造为模型内部百分比。
- `.layout-tasks/state.json` 与逐任务 JSONL 日志仅在本机隐藏目录保存，静态服务器禁止直接访问。刷新可恢复队列和候选；预览服务重启时，曾运行的任务标记暂停，必须明确继续。任务输入快照只用于本机一致性校验，不进入导出的 LOG。
- LOG 记录任务/尝试 ID、阶段、起止耗时、最近事件、调用上限、错误代码及结构化诊断；不写密钥、提示词或模型正文。支持单任务查看和多任务 JSON 导出。历史版本未保存的细日志无法追溯补回。
- 单任务 LOG 窗口提供“一键复制”“导出 JSON”和“关闭”。复制和导出使用当前窗口同一份脱敏 JSON 快照，不改任务、页面或历史；复制权限被拒会尝试本地复制回退，仍失败则明确提示手动选择或导出，不误报成功。底部工作区继续支持按所选任务导出，未选择时导出全部。
- 不同页的模型调用和校验可以并发，DOM 替换及保存串行进行；应用前校验该页输入快照，不跳到其他页面，不清空其他页的文字选择。发现等待期间新编辑则进入“编辑冲突”，保留新稿。新原模板按需补齐样式，避免内容已替换但画面空白。应用支持撤销/重做。

### 调试接口

GET `/api/layout-agent-status` 返回公开的连接与入口检查状态；POST `/api/layout-agent-config` 显式保存当前预览的连接。有未完成任务时不得切换连接。正常内容项目仍由原项目拥有连接；独立预览保存到本预览的私有目录，复制到新位置后需重新确认。连接设置不调用模型、不修改全局配置、不创建虚假的内容项目，也不更改页面或历史。`available` 仅代表已找到可调用入口，`runtimeTested:false` 明确表示没有验证实际登录、网络或模型响应。第一次真实任务仍可能报告这些运行时问题。

同源请求：GET `/api/layout-tasks` 查看任务与设置；POST `/api/layout-config` 设置 `concurrency/timeoutMs`；POST `/api/layout-order` 提交全部排队任务 ID 顺序；POST `/api/layout-batch-control` 提交 `{ids,action}`；GET `/api/layout-logs?id=...` 获取脱敏诊断。任务详情与原有控制端点保持兼容。不得通过开放局域网权限绕过同源检查。

## 原稿保护

- 当前页页数不变，不能借适配顺带增删其他页面。需要拆页仍使用脑图的拆页候选。
- 保留所有不同原始数值，禁止缺值、新增数值或改值；允许合并同一事实的重复数字表述，出现次数变化必须在审阅中单独列出，数字所属对象/单位/基准仍需人工确认，不能把不同对象的同值事实误合并。原结构化数据完全不变，图片引用和每条完整来源保留；来源可按真实归属移入对应块的 evidence，但仍由渲染器放在独立来源区，不埋入正文绕过容量。
- 每个候选块必须声明来自哪些原块；每个原块至少有去向，不能新建无来源内容块。映射覆盖不等于自动证明语义完整，UI 明确要求用户核对核心判断是否保留、因果或层级是否成立。
- 原始中性内容、原页面与原样式快照保留；候选的 before/after/changes/originMap 和校验结果写入本演示的 `.layout-cache` 审计快照。预览中的适配不自动改写脑图原稿；后续从脑图重新生成仍使用脑图内容。
- 特殊封面、章节和原样封底不参与正文适配。SVG 标签仍遵循 HTML 文字规则，导出不包含审阅窗口、进度和按钮。

## 开发验证

### 几何容量与修订反馈

原主题固定版式仍遵循单套唯一；`theme17_content_*` 与 `theme17_chart_*` 可复用。菜单、执行与规划共用同一规则，不因其他页已经使用自适应版式就排除它。候选缓存必须区分页面关系、视觉意图与实际媒体；时间线/流程候选保留真实顺序，不能为了套用构图虚构因果。入队前和执行前均校验目标与必要授权，过期或不兼容选择不启动模型。

字段字数上限不等于页面实际容量。ICON 适配提示必须从同一渲染器计算不同数量、图片开启状态下的 `geometryProfiles`；推荐分组数只是草拟建议，不放宽原始数值、来源、去向或实际页面检查。逐块来源占空间时，可把完整来源去重集中到独立来源区；不能删掉限定或伪造来源。

ICON 几何拒绝应包含 blockId、所需/可用高度，HW 原稿拒绝保留原校验器的具体原因。修订轮必须接收这些结构化诊断，不能只返回“分组或关系不匹配”再重复相同请求。相关单元回归检查所有 ICON 数量及有图/无图边界；真实业务稿另做隔离渲染与完整文字验证，不能把合成夹具当作真实稿件验收。

HW 自动内容映射使用原稿的独立来源区，保留每个原块来源到页脚的稳定绑定，不额外把来源段落塞进固定正文框。流程/时间线仅为现有可见图形补充关系识别属性，不新增或改变连接线。原稿文字检查使用真实文字范围，不把外伸连接线或空白边距算作正文溢出；被裁切的真实文字仍拒绝发布。中央指标四块档位的解释区仅适合一行，过长时在检索阶段排除该档位，保留其他完整可用的指标版式，不改原稿字号来强行承载。

### 任务状态与保存故障

入队、队列设置、排序和恢复失败必须回滚内存变更，不能留下未保存的排队锁。进度或诊断回调写入失败不得使服务崩溃；停止受影响的执行，保留原页，恢复写入后由用户明确继续。暂停/取消优先终止执行，即使保存失败也准确说明“执行已停止、状态未保存”。候选终态未持久保存时不得发布为可应用；迟到结果、重启及保存恢复均不得自动重发模型请求。

### 返回结构与容量（0.10.1）

AI 收到完整中性内容 `outputTemplate`，以及按 title/conclusion/label/text/evidence 表达的目标容量，不再把模板 arrays/props 字段混入返回契约。返回模板参数、遗漏 slideId/blocks 时给出针对性的结构错误；超容反馈列出目标的具体拒绝原因和中性容量，最多修订一次。不能通过补造 ID、丢弃字段、截断或放宽事实校验使错误结果通过。DeepSeek 对话中可明确选择本次推理强度，默认沿用；实时进度只统计生成长度，不展示或记录思考正文。

`npm run test:content` 测试模式路由、数字/来源/数据/图片/去向保护和原模板匹配。`node project/tests/content/adaptation-e2e.mjs` 使用明确标注的测试执行器验证真实浏览器确认、拒绝、暂停/继续、原主题渲染、撤销/重做、刷新与原脑图不变；不能把测试执行器当作调用生产 AI 的证据。
## 历史记录与重新尝试（0.10.2）

已结束任务默认保留原日志，侧栏显示历史记录，可隐藏提示；已完成及已停止的暂停/失败/冲突/取消任务可在任务工作区确认删除，页面与撤销栈不变。历史失败、取消、编辑冲突的重新尝试会重新读取当前页，重新计算可用版式并新建任务，不恢复旧输入。目标由直接换版变成需要 AI 时，先弹出适配配置与确认；没有可用目标则保留原页并要求重新选择。底部列表与侧栏遵循同一入口；批量继续仅针对暂停项，不批量重发历史失败任务。暂停继续仍使用原任务快照，应用前检查新编辑冲突。服务端拒绝旧客户端直接恢复历史失败任务。
