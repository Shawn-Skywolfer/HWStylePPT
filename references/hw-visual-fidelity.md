# HW 原稿忠实度与变更审批

## 视觉基准

2026-11-04 用户批准的全局文字修订：HW·设计感正文主标题与原稿标题同坐标、同字号（1280×720：64/40/1020/34px，行高1.25、字重700、字距-0.02em）；HW 原稿小标题、正文在各自原字号上增加2pt。此批准仅针对文字尺度与设计感标题位置，不授权修改其他构图、颜色、连线和变体。固定封面/章节/封底、大数字与单位、页脚和坐标轴不在此次增大范围。旧原稿文件保留作为对照，像素验收应明确扣除这项已批准的文字变化，不能宣称与旧原稿整页像素相同。

用户提供的 HW 模板包是视觉基准。注册表决定名称、布局键与允许的变体，原稿实际渲染决定各变体的外观。不能把“有相同数量的卡片”或“能表达相同关系”当成忠实还原。

逐项保留：

- 页面构图、主次关系、区域宽高比、跨格、对齐、留白与间隔。
- 图形形状、圆角、边框、填充、渐变、阴影和灰红配色。
- 文字层次、数字与单位的比例、标题带、日期层、详情区与图例的位置。
- 连接线的路径、颜色、粗细、端点、箭头方向与关系语义。
- 每个注册变体的数量、列数、行数、交错、强调项及跨格规则。

原来已确认的封面、章节、封底和品牌资产不因新增正文模板而改变。用户已要求的 ICON 库复用、图片来源/裁切/替换和结构化图表编辑是功能接入，不是重新设计页面的授权。

## 需要审批的偏离

真实内容超出原稿容量，或原稿图表在特定数值下不能正确表达数据时，不得自行缩小字号、挤压间隔、重排构图、改变图形或删去内容。也不得为了看起来像原稿而修改真实数据或关系。

先保留原始内容与当前页，再提供：

1. 原模板、变体及当前内容；指出具体不能承载或不能正确表达的位置。
2. 原样预览与拟改样预览。两者使用相同内容、相同比例和同一视口；标注发生变化的元素。若拟拆页，显示所有新页。
3. 必须改动的原因、影响范围、其他可选方案，以及正文/来源/关系/媒体是否变化。
4. 等待用户明确批准。批准限定在所展示的方案和页面，不能扩展成任意重设计的通用权限。

没有批准则不应用、不覆盖、不把候选写成正式稿。沿用已有快照和撤销历史。用户手动选择另一已批准模板并不授权修改该模板的默认视觉规则。

## 验收分开报告

功能验收检查数据、媒体、ICON、保存、换版、撤销与导出；视觉验收检查原稿忠实度。两者必须分别报告，不能用单元测试数或容量测试数代替视觉对照。

视觉验收必须覆盖 28 个模板的全部 77 个注册变体，不只检查默认档位。使用同一组内容做原稿和实现的并排对照；不同文案的截图只能用于结构审计，不能用于像素一致性结论。发现偏离先登记和修复，未批准的差异不能作为“内容自适应”豁免。

## 当前集成的修订注意

上一轮使用通用卡片与重新计算几何的方式产生过明显差异。不能沿用“生产组件无须还原原稿”的豁免。特别检查：转型双面板与驱动区、架构层内小格及解释区、径向中心胶囊与编号节点、时间线日期/引导线/图例；同时检查全部指标、Bento、图文、ICON、表格及图表的各自视觉结构。
