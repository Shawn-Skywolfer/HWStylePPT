# 0.17.5 · 换版可靠性

- 关系、角色和分组授权先于模型调用；已知不兼容不反复重试。
- 需要调整关系表达的目标单独标记、单独授权，并显示逐条关系去向；原页保留至候选确认。
- 图文 ICON 使用真实图片框的几何容量。
- HW 图文矩阵计入原稿标题带、内边距、空小标题间距与英文换行，不修改原稿构图或缩小字体。
- HW 图表说明使用原稿已有页下注释区域；说明与来源完整显示，往返换版不重复。
- 取消 ICON 页面只能切换 ICON 版式的误过滤，保留图标选择以供换回恢复。

已使用三份真实业务材料逐页验证。直接换版、需审阅的 AI 适配、容量不足及缺少真实数据分别记录，不把结构探测或安全拦截计为实际换版成功。固定封面、章节、封底不参与正文换版覆盖计数。

本机模型桥接仍受原宿主、权限、网络、模型响应及资源影响；测试执行器和协议回归不能冒充外部模型的逐目标实测。适配候选仍须通过完整内容、数值、来源、关系与真实浏览器检查；失败、取消或冲突不覆盖当前编辑，不为通过检查删改事实或放宽模板容量。
